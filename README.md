# QuoteDesk

Phase-1 asset for Project 2B.

A local, zero-backend desk for small cross-border sellers: unit full cost, FOB/CIF/EXW/DDP quote, USD conversion, gross profit, and a copyable quotation.

Open `index.html`. No account, no upload.

Commercial status: not for sale yet. No revenue has been booked.

License: source is public for evaluation. Paid packaging starts only after a real checkout exists.
